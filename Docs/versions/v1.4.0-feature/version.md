# 版本摘要 - v1.4.0-feature

1. 新增自定义供应商（Custom Provider / Script Provider），支持用户配置本地脚本获取模型配额与用量。
2. 规范化脚本输出的 JSON 结构契约，支持动态定义重置时间、多额度窗口（5小时、周度、月度、余额等）。
3. 内置进程沙箱与超时中断保护（默认 10 秒），防止外部脚本挂起阻塞监控刷新。
4. Settings 设置面板新增脚本路径配置与即时测试交互，无缝接入面板悬浮环与卡片视图。
5. 支持一个脚本返回多个自定义供应商组；可在“Ring shows”中选择“所有分组”，每组显示主额度和第二层额度环。
6. 自定义供应商可从 Pulse 内置图标中选择；脚本可通过 `providers[].icon` 为每个额度组指定预置图标。
